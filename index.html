How I work

  1. Speed is felt, not seen.

    I split the code, load what is needed when it is needed, and cache the rest. Nobody should notice the page. It should simply be there.

  2. Let the agents write. Let the tests decide.

    I build with AI coding agents, and I trust the process more than the agent. Every change arrives as a pull request that clears lint, type checks, tests and end-to-end runs before review.

  3. Begin together.

    Good work starts before the first line of code. I sit with designers and clients to shape what gets built, then help the people beside me grow through review and mentoring.
